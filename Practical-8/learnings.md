P-1
In this We learned how to perform inorder, preorder and postorder traversal using recursion and level order traversal using a queue.
We also learned how the visiting order changes the sequence in which tree nodes are displayed.
P-2
We learned how to create a Binary Search Tree by comparing each new value with the existing nodes and inserting it at the correct position.
We also learned that inorder traversal of a BST produces the elements in sorted order.
