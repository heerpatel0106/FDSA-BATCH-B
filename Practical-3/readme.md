#Learnings of Practical-3
P-1
We learned how to implement Bubble Sort, Selection Sort and Insertion Sort and understood how each sorting method arranges the elements differently. We also learned that Insertion Sort is faster when the array is already sorted because it requires very few operations.

P-2
We learned how to sort an array containing 0, 1 and 2 without using extra storage. We used three pointers, low, mid and high, to arrange the elements in one pass. This helped us understand in-place sorting and the Dutch National Flag approach.
