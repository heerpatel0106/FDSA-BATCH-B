In this practical i learnt the concept of searching of two types:
1) Linear Searching: Serching every element from beginning until the key is found.
2) Binary Searching: Searching element by dividing the array in two halves(which works on sorted array only)

In both we learnt iterative and recursive type.

Iterative Approach:
The iterative approach uses a loop (for or while) to repeat the same task until a condition is met. In this practical, we used a for loop to check each element of the array one by one. The loop stops immediately when the target element is found or after checking all elements.

Recursive Approach:
The recursive approach uses a function that calls itself to solve the problem. In this practical, the function checks one element of the array at a time. If the element is not the target, it calls itself to check the next element. This continues until the target is found or all elements have been checked.

The base case is the stopping condition in a recursive function. It prevents the function from calling itself forever.
